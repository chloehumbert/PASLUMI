⚙️ Lancer le projet en local
Prérequis

Go ≥ 1.20

Installation & démarrage
bash# Cloner le dépôt
git clone https://github.com/votre-utilisateur/paslumi.git
cd paslumi

# Télécharger les dépendances Go
go mod tidy

# Lancer le serveur
go run main.go
Le site sera accessible sur http://localhost:8080
Ou avec l'exécutable Windows
bash./paslumi.exe
